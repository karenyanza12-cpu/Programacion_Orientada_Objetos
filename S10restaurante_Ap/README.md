## Descripción del proyecto

Este proyecto corresponde a la evolución del sistema `restaurante_app` desarrollado durante las semanas anteriores de la asignatura Programación Orientada a Objetos.

El sistema representa la administración básica de productos y usuarios de un restaurante. Para la Semana 10 se incorporó la persistencia de productos mediante un archivo JSON, permitiendo que los productos registrados permanezcan disponibles aunque el programa se cierre y se vuelva a ejecutar.

El proyecto mantiene una organización modular utilizando clases, servicios y un archivo principal para la interacción con el usuario.
